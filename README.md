# FreeShelf

Created by Akash Vishwakarma. A mobile-first directory of free learning and developer resources with clear limits and official source links.

## Features
- 11 resources across courses, hosting, certificates, AI tools and resume builders
- English and Hinglish display
- Light and dark themes, saved across visits; initial theme follows the system
- Search and category filters, plus a filter to hide limited free tiers
- Save resources locally with no account
- Accessible dialogs with source links and certificate requirements

## Run
Open `index.html`, or serve this folder with any static web server. No installation or backend is needed. For GitHub Pages, deploy `main` from the repository root.

## Privacy and cost
The directory has no ads, analytics, account creation or payment flow. Theme, language and saves are stored in the browser only and do not sync. Listed services may have paid upgrades or restricted free tiers; their terms can change. This project does not enable billing for visitors.

## Content
Official sources were checked on 8 October 2026. Resource data is embedded in `index.html`. Check the linked sources before changing a cost, quota or certificate claim. Free courses do not always offer free certificates. This directory is not affiliated with the listed providers.

## Maintenance
Update the resource entries and their checked date when provider terms change. No API keys, paid hosting or dependencies are required.
